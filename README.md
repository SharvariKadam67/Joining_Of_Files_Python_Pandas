# Python File Handling and Joining Program

Project Overview

This project demonstrates how to fetch files from a specified folder and join them based on predefined conditions using Python.

It is designed as a practice project for learning Python programming concepts and file processing.

Libraries Used

* Pandas – For reading, manipulating, and joining datasets.
* OS – For accessing files and directories and retrieving file metadata.
* Datetime – For working with dates and timestamps.

--Concepts Covered--

- File handling and directory operations
- Loops and conditional statements (`if-else`)
- Lambda functions
- List comprehensions
- Date and time operations
- Selecting files based on creation or modification time
- Joining datasets using Pandas

Prerequisites

- Python 3.x
- Pandas library

Install Pandas using:

```bash
pip install pandas
```

The `os` and `datetime` modules are included with Python and do not require separate installation.

## How to Run

1. Clone or download this repository.
2. Update the folder path in the program to point to your input files.
3. Ensure the required input files are available in the specified folder.
4. Run the Python script:

```bash
python StockSplit_joining_program.py
```

## Learning Objective

The goal of this project is to gain practical experience with Python file handling, file selection, conditional logic, and data joining.
