Python File Handling and Joining Program

This program fetches files from a specified folder and joins them based on predefined conditions.

The following Python libraries must be imported before executing the program:
* Pandas – for data manipulation and joining files.
* OS – for file and folder operations.
* Datetime – for handling dates and timestamps.

This program provides hands-on practice with the following Python concepts:
- File handling
- Loops and conditional statements (`if-else`)
- Lambda functions
- List comprehensions
- Date and time operations
- File selection based on creation or modification time
- Joining datasets using Pandas
